# Desktop Excel Automation & Data Cleaning Tool

A high-performance data processing desktop utility built with Python to streamline office automation, data preparation, and corporate logging workflows. 

## 🚀 Key Features
* Pandas Integration: Seamlessly loads, processes, and manipulates massive Excel and tabular datasets.
* Smart Data Diagnostics: Automatically scans rows for missing values (NaN) and highlights them dynamically in the UI for data cleaning.
* Optimized TreeView Rendering: Limits initial row rendering to 1,000 records, preventing the graphical interface from freezing during heavy dataset parsing.
* Targeted Sorting: Features columns-specific data sorting logic built into a lightweight desktop GUI.

## 🛠️ Tech Stack
* Data Analytics: Pandas, NumPy
* GUI Framework: Tkinter (Ttk TreeView Component)
